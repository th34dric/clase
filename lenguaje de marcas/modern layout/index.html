1. Demostración de Flexbox vs CSS Grid

El menú de navegación superior utiliza display: flex para alinear el logo y la lista horizontalmente en 1 dimensión.

El contenedor global utiliza display: grid para organizar la barra lateral (<aside>) y el contenido principal (<main>) en 2 dimensiones.

2. Galería en CSS Grid (Responsive Automático)

La siguiente rejilla ajusta el número de columnas según el tamaño de pantalla mediante repeat(auto-fit, minmax(220px, 1fr)) sin usar Media Queries.

Artículo 1: Flexbox

Ideal para alinear elementos unidimensionales como menús, listas e inputs.

Artículo 2: CSS Grid

Ideal para estructuras bidimensionales complejas y galerías de elementos.

Artículo 3: Box Model
